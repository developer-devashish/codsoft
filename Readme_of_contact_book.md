# Contact Book Application

A simple and modern Contact Book application built using Python Tkinter.

This application allows users to:
- Add contacts
- Search contacts
- Update contact details
- Delete contacts
- View all saved contacts

The project includes a clean graphical user interface with modern styling and user-friendly features.

---

# Features

- Add New Contacts  
- View Contact List  
- Search Contact by Name or Phone Number  
- Update Existing Contact  
- Delete Contact  
- Clear Input Fields  
- Contact Not Found Message  
- Modern GUI Design  
- User-Friendly Interface
